# Google Search Console

Verify the domain at your DNS provider—no HTML meta tags in the repo.

1. Open [Google Search Console](https://search.google.com/search-console) and add the **domain** property for `bf6cheats.org` if it is not already there.
2. Add the DNS TXT record Google provides at your DNS host.
3. After verification, submit `https://bf6cheats.org/sitemap.xml`.
