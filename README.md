# BF6 Cheats

Battlefield 6 cheats marketing site for **bf6cheats.org**, built from the master Astro template.

## Site config

Edit `src/config/site.ts` for domain, product paths, and CTA URL. Checkout redirects live in `src/config/checkout-redirects.mjs`.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
